Ejercicio 4: Página de Ancho Variable (Fluido)

Esta versión utiliza un diseño de ancho variable (fluido). Si redimensionas la ventana del navegador, el contenido se encogerá o expandirá de forma dinámica para adaptarse a la pantalla.

Se ha configurado usando width: 90%; junto con max-width: 1200px; para una respuesta óptima.
